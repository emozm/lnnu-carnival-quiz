# 敢闯会创 · 筑梦辽师

辽宁师范大学校科创协会社团嘉年华有奖竞答网站。

答题入口：https://emozm.github.io/lnnu-carnival-quiz/

## 活动规则

题库43道；每轮随机抽取15道，同轮不重复：简单5题×4分、普通5题×6分、困难5题×10分，满分100分。单项选择，答错不扣分。答完显示成绩和“凭成绩到摊位咨询兑换”。

## 文件

- index.html：页面内容
- styles.css：手机/电脑布局、滚动渐入与交互样式
- app.js：随机抽题、计分、浏览器进度保存
- motion.js：按钮吸附、卡片倾斜和触摸反馈
- data/：简单、普通、困难题库
- assets/icons/：本地Lucide SVG及完整许可证

## 本地预览

在仓库目录执行：

```sh
python -m http.server 8765
```

打开 http://localhost:8765/ 。请使用HTTP预览，直接双击HTML可能无法读取题库。

## 发布

GitHub Pages使用main分支的根目录。网站不依赖构建工具、账号登录或外部图标CDN。修改文件并提交至main后，Pages会更新。

## 使用边界

答题进度和成绩仅保存在当前浏览器。此版本没有身份验证、跨设备限次或兑换核销后台；清理浏览器数据或换设备可重新参与。成绩兑换以现场工作人员说明为准。

题库及协会介绍由活动资料和学院公开信息整理。页面主题为本次活动文案，非学院正式口号。图标来源Lucide，许可证见assets/icons/LICENSE-lucide.txt。
